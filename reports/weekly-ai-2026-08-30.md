## 🏆 本周精选（8 个，按实用性分组）

### 🎨 图像创作

**1. awesome-gpt-image-2 —— GPT-Image2 提示词引擎与模板库**
- ⭐ 本周新增 **13,141**（本周 AI 项目增速第一）
- 🎯 功能：逆向解析 530+ 真实案例，沉淀 20+ 套工业级提示词模板（海报、产品图、电商主图等），把"GPT 画图"变成可复制的工序；附带可落地的 Skills
- 👤 为什么适合你：不用会设计，套模板改关键词就能出图，电商配图 / 小红书封面 / 朋友圈海报都能用
- 🔗 https://github.com/freestylefly/awesome-gpt-image-2

**2. open-higgsfield —— 一站式图像/视频生成工作室**
- ⭐ 1,047（8/26 新建，一周破千星）
- 🎯 功能：一个提示词输入栏，各自模型独立参数，所有生成成品自动汇总进一个作品画廊，方便对比挑选
- 👤 为什么适合你：把多个生图/生视频模型收拢到一个界面，省去来回切换，适合做内容试产
- 🔗 https://github.com/wide-trace/open-higgsfield

### 💼 求职提效（本周与你最相关的方向）

**3. ai-job-search —— 跑在自己电脑上的 AI 求职助手**
- ⭐ 总 **38,297**，本周 +5,145
- 🎯 功能：基于 Claude Code 的求职框架——评估职位匹配度、按 JD 定制简历、写求职信、准备面试问题；整套流程 fork 后完全自用、数据不出本机
- 👤 为什么适合你：正在投电商运营/多岗位适配，正好可以拿它批量分析 JD、针对性改简历、模拟面试
- 🔗 https://github.com/MadsLorentzen/ai-job-search

### 🎬 视频剪辑

**4. WolfCut —— 免费开源的剪映替代品**
- ⭐ 567（8/25 新建，一周上榜）
- 🎯 功能：视频剪辑 + 音频处理 + 智能切片（clipping），底层用 FFmpeg 驱动，主打剪映（CapCut）的免费开源平替
- 👤 为什么适合你：做电商短视频、口播切片不用再买剪映会员，完全本地运行
- 🔗 https://github.com/jub0t/WolfCut

### 🎙️ 语音字幕

**5. 早耳 hayamimi —— 纯 CPU 实时多语言语音转文字**
- ⭐ 308（8/25 新建）
- 🎯 功能：实时语音转写 + 实时字幕 + 浏览器控制台 + 说话人区分 + 翻译；**无需 GPU、无需联网、纯本地跑**
- 👤 为什么适合你：开会议、看直播、听课做字幕，低配电脑也能用，隐私数据不出机器
- 🔗 https://github.com/oboroge0/hayamimi

### 🧠 个人效率 / 智能体

**6. openhuman —— 本地优先的个人 AI 超级智能**
- ⭐ 本周 +2,434
- 🎯 功能：生活记忆大脑（记录你的日常偏好与信息）+ 智能体舰队 + 工作流编排 + 深度研究助手，主打"把 AI 变成了解你的私人助理"
- 👤 为什么适合你：想搭个人知识/记忆系统、让 AI 越用越懂你的普通用户
- 🔗 https://github.com/tinyhumansai/openhuman

**7. freellmapi —— 免费 LLM API 统一网关**
- ⭐ 本周 +2,691
- 🎯 功能：聚合 34 个免费 LLM 提供商、635 个免费模型端点，统一走一个 /v1 接口，支持智能路由与故障自动切换（个人实验用途）
- 👤 为什么适合你：想给自己的工作流/小工具接 AI，但不想花钱充 API 的人，一套接口白嫖多家模型
- 🔗 https://github.com/tashfeenahmed/freellmapi

### 📚 学习成长

**8. OpenMAIC —— 清华开源的多智能体互动课堂**

- 👤 为什么适合你：自学电商运营、AI 工具等新领域时，有"AI 导师团"陪练
